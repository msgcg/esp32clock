# 🕰️ ESP32 Smart Clock with Emotional Eyes

![ESP32 Smart Clock](https://via.placeholder.com/800x400/0a0f1a/ffffff?text=ESP32+Smart+Clock+%7C+Emotional+Eyes+%7C+Weather-Aware+Themes)

Умные часы на базе ESP32 с анимированными глазами, меняющими эмоции, автоматической сменой тем под время суток и погоду, и бережным ночным режимом без синего света. Идеальный ночной компаньон для спальни! 😴❤️

## 🔌 Схема подключения

```
┌──────────────┐       ┌──────────────┐
│   ESP32      │       │  ST7735 TFT  │
│              │       │  0.96" 80x160│
│  GPIO6  ─────┼───────┼─ MOSI        │
│  GPIO4  ─────┼───────┼─ SCLK        │
│  GPIO5  ─────┼───────┼─ DC          │
│  GPIO0  ─────┼───────┼─ CS          │
│  GPIO8  ─────┼───────┼─ RST         │
│              │       │  VCC ── 3.3V │
│              │       │  GND ── GND  │
└──────┬───────┘       └──────────────┘
       │
       ├───────────────┬──────────────┐
       │               │              │
┌──────▼──────┐ ┌──────▼──────┐ ┌────▼──────┐
│  DHT11      │ │  IR RX      │ │  Реле     │
│  GPIO2      │ │  GPIO3      │ │  GPIO10   │
└─────────────┘ └─────────────┘ └───────────┘
       │               │              │
┌──────▼──────┐ ┌──────▼──────┐ ┌────▼──────┐
│  Зумер      │ │  Лампа      │ │  Питание  │
│  GPIO7      │ │  220V AC    │ │  5V USB   │
└─────────────┘ └─────────────┘ └───────────┘
```

### Таблица пинов

| Компонент | Пин ESP32 | Назначение |
|-----------|-----------|------------|
| **ST7735 TFT** | GPIO6 | MOSI (данные) |
| | GPIO4 | SCLK (тактовая) |
| | GPIO5 | DC (режим данных/команд) |
| | GPIO0 | CS (выбор чипа) |
| | GPIO8 | RST (сброс) |
| **DHT11** | GPIO2 | Данные температуры/влажности |
| **IR приёмник** | GPIO3 | Приём команд с пульта |
| **Реле** | GPIO10 | Управление лампой/ночником |
| **Зумер** | GPIO7 | Звуковой сигнал будильника |

## ⚙️ Установка и настройка

### 1. Требования

- **Микроконтроллер:** ESP32 (любая модель)
- **Дисплей:** ST7735 0.96" 80x160 (китайская копия)
- **Датчики:** DHT11, ИК-приёмник VS1838B
- **Актуаторы:** Реле 5В, пьезо-зумер
- **Библиотеки:**
  ```ini
  lib_deps = 
      adafruit/Adafruit GFX Library@^1.11.3
      adafruit/Adafruit ST7735 and ST7789 Library@^1.9.0
      crankyoldgit/IRremoteESP8266@^2.8.6
      adafruit/DHT sensor library@^1.4.6
  ```

### 2. Сборка проекта

```bash
# Клонирование репозитория
git clone https://github.com/yourname/esp32-smart-clock.git
cd esp32-smart-clock

# Установка зависимостей (PlatformIO)
pio lib install

# Загрузка на устройство
pio run -t upload --upload-port COMx
```

### 3. Настройка конфигурации (`config.h`)

```cpp
// --- TFT (Software SPI) ---
#define TFT_MOSI    6
#define TFT_SCLK    4
#define TFT_DC      5
#define TFT_CS      0
#define TFT_RST     8

// --- Сенсоры ---
#define PIN_DHT     2
#define PIN_IR      3

// --- Актуаторы ---
#define PIN_RELAY   10
#define PIN_BUZZER  7
```

> ⚠️ **Важно для копий дисплея:** Макрос `RGB()` в коде уже настроен для китайских модулей с перепутанными цветовыми каналами. Не изменяйте его без необходимости!

## 🎮 Управление через ИК-пульт (Car MP3)

### Быстрые действия (в режиме часов)

| Кнопка | Действие |
|--------|----------|
| **CH-** | Вкл/выкл лампу (ночник) |
| **CH+** | Следующая мотивационная цитата |
| **PLAY/PAUSE** | Переключить: часы ↔ анимация глаз |
| **EQ** | Открыть главное меню |
| **5 / 7 / 9** | Быстрая установка будильника (5:00 / 7:00 / 9:00) |
| **200+** | Сброс всех будильников |

### Навигация по меню

```
┌──────────────────────────────┐
│  📋 ГЛАВНОЕ МЕНЮ             │
├──────────────────────────────┤
│  ⏰ Время                     │ ← Выбор стрелками ▲ ▼
│  🔔 Будильник                │    Подтверждение: 100+
│  💡 Свет                     │    Выход: EQ
│  💬 Цитата                   │
│  🎵 Звук (в разработке)      │
└──────────────────────────────┘
```

### Установка времени/будильника

- **▲ / ▼** или **+ / -** — изменение значения
- **◄ / ►** — переключение между часами и минутами
- **Цифры 0-9** — быстрый ввод времени
- **100+** — сохранить и выйти

## Цветовые темы и автоматика

### Смена тем по времени суток

| Время | Тема | Цветовая температура | Синий спектр |
|-------|------|----------------------|--------------|
| **06:00–08:59** | Рассвет | 4500K | 15% |
| **09:00–17:59** | День | 6500K | 30% |
| **18:00–22:59** | Закат | 3500K | 10% |
| **23:00–05:59** | Ночь | 2200K | **0%** ✅ |

### Смена тем по погоде (днём)

| Условие | Тема | Визуальный эффект |
|---------|------|-------------------|
| `Темп. > 28°C` | Осень | Тёплые оранжевые тона |
| `Темп. < 15°C` | Зима | Холодные синие тона |
| `Влажность > 70%` | Весна | Зелёные тона + дождь 🌧️ |
| `Влажность < 30%` | Лето | Голубые тона + песок 🏜️ |

## 👀 Эмоции глаз (14 состояний)

| Эмоция | Визуальные признаки | Триггер |
|--------|---------------------|---------|
| 😊 **Счастье** | Зрачки вверх + щёчки | Случайно (40% шанс) |
| ❤️ **Влюблённость** | Сердечки вместо зрачков | Случайно (8% шанс) |
| 😉 **Подмигивание** | Один глаз закрыт | Случайно (4% шанс) |
| 😠 **Злость** | Брови вниз, зрачки вниз | Случайно (3% шанс) |
| 😢 **Грусть** | Брови вверх дугой | Случайно (3% шанс) |
| 😮 **Удивление** | Большие глаза, маленькие зрачки | Случайно (5% шанс) |
| 😴 **Сонливость** | Полный прищур | Ночью (23:00–06:00) |
| 😑 **Усталость** | Лёгкий прищур | После 22:00 |
| 👀 **Взгляд** | Зрачки влево/вправо/вверх/вниз | Случайно |

> 💡 Эмоции меняются каждые 15 секунд с приоритетом на позитивные состояния (70% шанс на 😊❤️😉)
